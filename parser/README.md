**Что реализовано**
* Посты
* Вложения (image)
* Комментарии (с image)
* Вложенные посты (репосты, с image)

**Подготовка:**

Поместите в директорию `parser/src/main/resources` файл с названием `wall_comments.json`

**Как запустить:**

Запустить можно с помощью `Docker` (запускать из директории `parser`, в которой располагается `Dockerfile`):
```
docker build --tag image_name .
docker run --name my_container image_name
```
После завершения (если программа не завершилась сама, нажать ctrl+c) выполнить
```
docker cp my_container:/usr/app/database.sqlite ./database.sqlite
```
Удалить Docker-контейнер:
```
docker rm my_container
```
Файл `database.sqlite` будет размещен в директории `parser`.

В целом Docker используется для удобства. Можно собрать и запустить вручную с помощью **mvn**.

**Заметки**

1. Посты выбираются по LIMIT=10 (в будущем по смещению).
2. Список всех Image для текущих постов выбирается из базы для всех постов из запроса сразу, потом распределяется (не у всех постов есть вложения).
3. Аналогично, список всех InnerPost для текущих постов выбирается из базы для всех постов из запроса сразу. Не у каждого поста есть InnerPost'ы (и зачастую там, где они есть, это будет 1-2, редко больше).
4. Аналогично, список всех Image для InnerPost'ов подгружается разом, а потом распределяется.
